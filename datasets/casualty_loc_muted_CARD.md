# casualty_loc_muted

Multi-event casualty documents in which a fraction of the interference snippets keep their
**text** but lose their **record**, so their figures become negatives for the same queries.

Built for cross-event contamination: on a real Hurricane Helene feed, 4.7% of extracted
casualty figures belong to a *different* event (Katrina's 1,400, a typhoon's 250, Milton's
230, Bosnia's 16, Hurricane John's 2 in Mexico), and those carry the largest values, so they
do the most damage per instance.

## Why negatives at all

Three decode-side signals were tried against this defect and all failed, because in every
cross-event case **the type is right**: Katrina's 1,400 scores `death toll` 0.95. Sharper
type boundaries cannot separate Helene's dead from Katrina's dead.

The gap is supervision. Measured over 20,000 records of each earlier corpus, **0.0% of
training documents have zero records** -- the model has never once been shown a casualty
figure it is supposed to leave alone. This corpus is the first that does.

| file | mute prob | documents | instances |
|---|--:|--:|--:|
| `casualty_loc_muted.train.jsonl` | **0.35** | 23,713 | 46,653 |
| `casualty_loc_muted.val.jsonl` | 0.0 | 2,704 | 6,761 |
| `casualty_loc_muted.test.jsonl` | 0.0 | 2,873 | 7,058 |

9,765 train documents (41.2%) carry a muted snippet, and **14,955 figures are delivered
unlabelled**.

## The control is `whr778/casualty_loc_split`, and the pairing is verified

Same streams, same contexts, same splits, built by the same builder at
`--mute-interference-prob 0.0`. Verified rather than assumed:

- every muted document's text is present in the control -- **0 absent**
- **9,669** documents carry strictly fewer records, and **none** carry more
- val and test are built at 0.0 and are **byte-identical** to the control's
- the stream partition reproduces `casualty_loc_split.train.jsonl` **byte-identically**

The 31 documents the control has and this lacks are focal-collision cases where every
interference record was also muted. They are dropped rather than emitted with empty gold,
because the focal toll is real but ambiguous and empty gold would teach suppression of a
genuine figure.

## Splits

23,713 / 2,704 / 2,873 documents over 200 / 25 / 25 streams. **Place-disjoint**: 0 duplicate
documents within a split, 0 across any pair, streams disjoint, and 0 shared location strings
between any pair of splits. Built from `train` streams only -- the real-event evaluation
feeds come from `test`, and that separation is what keeps the evaluation uncontaminated.

## Two limits, declared

1. **The focal snippet is always the first**, so muting is learnable from POSITION alone --
   "extract from the first paragraph" scores perfectly here without representing event
   identity at all. Real articles do lead with their focal event, so the prior is not pure
   artifact, but this corpus cannot distinguish the shortcut from the intended behaviour.
   Score `whr778/casualty_loc_probe_focal_last` before reading any gain as event identity.
2. **8 DocEE event TYPES, no named identities.** What this can teach is "this figure belongs
   to a different incident", by place and type. It cannot teach "Helene versus Katrina" by
   name, which is same-type same-region discrimination and remains open.

## Provenance

Synthetic stream trajectories (exact ground truth) paired with real DocEE contexts -- actual
event types and place names -- realized as text by an LLM. The text carries **no fabricated
news-agency credit**; an earlier realization opened some snippets with datelines attributing
synthetic prose to real agencies, and those were scrubbed.

Generated by `datasets/disaster_streams/build_multievent_corpus.py`.
