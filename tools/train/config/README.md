## `archive/`

Configs whose experiment is **finished and reported**, and which are not expected to run
again. Kept rather than deleted: they are the record of what was actually run, and several
working papers cite them by path.

| | why |
|---|---|
| `span/archive/` (31) | the fastino-v1 **span** line, superseded by the boundary architecture. `scripts/train_all_events.sh` and `scripts/train_redocred.sh` still drive these and now default `CONFIG_DIR` here, so they keep working. |
| `base/archive/` (7) | the `mmbert-small-*` struct-loss sweep. It picked a winner — `bce_posweight` — which is now the default in every live config. |
| `probe/archive/` (5) | NaN diagnostics and parity checks. The NaN root cause was found (sdpa + bf16 on mmBERT) and fixed, so the probes have no question left. |
| `tier2/archive/` (4) | both Tier 2 event-record experiments, MAVEN and CASIE. Complete and **negative**. |

**Deliberately not archived:** the `warmstart-natural-*` family and
`warmstart-137k-realsynth-replay30`. Their runs consumed structure supervision that turned
out to be silently undecodable (TRAINING.md §3a), so they are re-run candidates, not
finished work.

## Two things that bite when a config moves

**Relative assets resolve by walking UP.** `labels_file: labels/unified.yaml` and
`stopword_yaml: stopwords.yaml` name files at the *root* of this tree, not beside the
config. `_resolve_beside_config` in `train.py` searches the config's own directory and then
its ancestors, stopping at `config/`. Before that fix, moving configs into subfolders broke
31 configs loudly on `labels_file` and 29 more **silently** on `stopword_yaml` — the silent
half worse, since a warm start against a label space the base never learned is exactly what
the shared file exists to prevent. A config can now move between folders without being
edited.

**The config test is recursive.** `tests/test_train_configs.py` uses `rglob`, so every
config in every subfolder — archive included — is validated, and it asserts each config's
relative assets resolve from where it sits. It used a non-recursive `glob` before, which
never validated the 20 `ab/` configs and would have validated *nothing* after this move
while still passing green.
