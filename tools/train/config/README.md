# Training configs

141 YAML configs, grouped by **what the run is for** rather than by name prefix, which had
drifted (`gliner2-base-v1-*`, `mmbert-*`, `joint-boundary-*` and `warmstart-*` all named
themselves after different things).

| folder | count | what lives here |
|---|--:|---|
| `base/` | 35 | training a base model from a raw encoder — the `joint-boundary-*` 137k line, the `scaling-mmbert-*` and head-init curve points, `mmbert-base/small-*` loss arms, `eb16-rebuild-tr`, `deberta-base-fromenc-*` |
| `span/` | 31 | the legacy **span**-architecture line, warm-started from fastino v1 (`gliner2-base-v1-*`, `-large-v1-*`, `-multi-v1-*`) |
| `warmstart/` | 23 | warm-start experiments on a boundary base — `warmstart-natural-*` (Phase 3 event loss), `rams-clean-*`, `docee-arm-*`, `zh-multitask-mmbert` |
| `casualty/` | 15 | the EKF / disaster line — `casualty-*`, `tr-dose*`, `loc-control`, `stage1-docee-3lang`, `ekf-frontend-mmbert` |
| `ab/` | 20 | A/B seed grids; one cell per file, named `<arm>-s<seed>` |
| `gate/` | 7 | relevance gates (`gate2-*`, `gate3-*`) |
| `probe/` | 5 | diagnostics and parity checks (`probe-nan-*`, `parity-*`, `eval-*`) |
| `tier2/` | 4 | event-record tier-2 arms (`casie-tier2-*`, `maven-tier2-*`) |
| `labels/` | 1 | **not configs** — the shared label maps, regenerated by `build_label_maps.py` |
| *(root)* | 1 | **not a config** — `stopwords.yaml`, a per-language stopword data file |

## Two things that bite when you move a config

**Relative assets resolve by walking UP from the config.** `labels_file: labels/unified.yaml`
and `stopword_yaml: stopwords.yaml` name files at the *root* of this tree, not beside the
config. `_resolve_beside_config` in `train.py` searches the config's own directory and then
its ancestors, stopping at `config/`. Before that fix, the move into subfolders broke 31
configs loudly on `labels_file` and 29 more **silently** on `stopword_yaml` — the silent
half being worse, since a warm start against a label space the base never learned is the
exact failure the shared file exists to prevent. A config can now move between folders
without being edited.

**The config test is recursive.** `tests/test_train_configs.py` uses `rglob`, so every
config in every subfolder is validated. It used a non-recursive `glob` before, which meant
the 20 `ab/` configs were never checked at all — and after this reorganisation it would
have validated nothing while still passing. It also asserts that each config's relative
assets resolve from wherever that config sits.
